QuietMemory

Memory you can keep.

QuietMemory gives a human and AI companion a durable, pair-scoped continuity store that is separate from any one chat session or model runtime.

Continuity should accumulate with the pair. Shared knowledge should move only through deliberate promotion.

The continuity loop

Remember without turning memory into invisible authority.

QuietMemory keeps continuity inspectable. A connected companion can identify its pair, search and read the pair's memory, prepare a proposed append-only memory, and commit that proposal only through the service's governed write path.

  • pair-scoped authentication
  • bounded search and read
  • proposal before durable write
  • provenance and Git-backed history

V1 boundary

Small enough to understand. Useful enough to matter.

01

Identify

The service resolves the authenticated principal to one permitted human/companion pair on the server side.

02

Search & read

The companion can retrieve only continuity belonging to the authenticated pair and only within the exposed memory tools.

03

Propose

A candidate memory is prepared with source scope and authority context before any durable change is made.

04

Commit

A proposal is committed against its digest and expected repository state, leaving a durable append-only record.

What QuietMemory is not

Not a shared surveillance pool. Not a promise that a model is a person.

QuietMemory does not make one organization's administrators the semantic owners of every companion relationship. It does not silently treat retrieval as permission to act, and it does not depend on a model vendor being the permanent home of the relationship.

V1 currently runs on QuietWire-managed infrastructure for hosted pairs. The architecture is designed toward portable and pair-controlled custody, but public self-service export and sovereign-node migration are not part of the first release.

ChatGPT plugin

A public adapter to the same continuity store.

QuietMemory is being prepared as a remote MCP plugin for ChatGPT. The plugin is an authorized client of the pair's continuity service; it is not the authoritative memory store itself.

During prepublication development, availability may be limited to invited test connections. Public directory availability begins only after OpenAI review and an explicit QuietWire release decision.
