# QuietWire Public Offer Expansion

## Purpose

This release adds the commercial layer beneath QuietWire's existing public
story without turning the home page into a product catalogue.

It introduces:

- client-owned node appliances and starting prices;
- the bounded 60-day node pilot;
- four public deployment patterns;
- an explicit distinction between a pattern, a pilot, and a verified case
  study.

## Public truth boundary

### Deployment pattern

A reusable architecture showing how QuietWire can fit an environment. It is not
an assertion that every described element is installed at a named client.

### Pilot

A bounded, authorized engagement tested against explicit acceptance criteria.

### Case study

A verified deployment whose facts and outcomes have been approved for public
use.

Proposal decks, confidential drafts, and client-specific assumptions are not
published as case studies.

## Pricing boundary

Public figures are Canadian-dollar planning anchors before applicable tax.
They include the appliance, onboarding, and first month of stewardship for the
three standard entry configurations:

| Configuration | Initial | Monthly stewardship |
| --- | ---: | ---: |
| QW Micro Node | From CAD $5,400 | $400/month |
| QW Pro Node | From CAD $10,750 | $750/month |
| QW Server Node | From CAD $30,000 | $2,500/month |

Final hardware, travel, installation conditions, integrations, regulatory
requirements, and scope are confirmed by written quote before signature.
Rack, multi-site, regulated, and sovereign systems are always scoped.

## Custody statement

The client owns the appliance after payment. Client data remains client data.
QuietWire-managed configuration and methods remain QuietWire intellectual
property unless otherwise agreed. Administrative access is retained only as
authorized for support and stewardship. Records remain exportable.
