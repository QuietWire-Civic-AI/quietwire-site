# The Inevitability Curve — origin note

Status: first-person historical recollection captured 2026-08-30; documentary verification pending.

## Source class

This note preserves Chris Blask's live recollection of the origin and continued use of the phrase **The Inevitability Curve**. It is not an independently verified 1991 or 1992 publication record, and it must not be used to manufacture one.

The exact origin year is uncertain in the recollection: **1991 or 1992**.

## Recollection

Chris recalls coining the term while trying to persuade his boss that everyone on Earth was going to get on the Internet.

The argument was not simply that a networked future was likely. It was that if the future state was effectively inevitable, then a line already connected the present to that notional future. People living in that future would be able to look backward and see the exact shape of the path that had carried the world there.

That path was **the inevitability curve**.

The immediate practical argument was security engineering: if universal Internet connectivity lay on that curve, then the organization should stop treating connectivity as a remote possibility and **go ahead and build a firewall**.

Chris recalls using the phrase and the underlying idea continuously ever since. In his account, the later work is related to the same line of thought: understand the future state that is already exerting pressure on the present, inspect the path between them, and make useful decisions now without pretending the exact route is simple or predetermined.
