# QuietMemory Gate C — public surfaces

**Date:** 2026-09-25  
**Status:** prepublication source on `feature/quietmemory-gate-c-v1`

This branch prepares the public pages needed for the first OpenAI plugin submission:

- `/quietmemory/` — product/website URL;
- `/quietmemory/support/` — support URL;
- `/quietmemory/privacy/` — product privacy notice;
- `/quietmemory/terms/` — product terms.

The pages are intentionally English-only for V1 and are not added to primary navigation.

## Boundary

A merged Git commit is not production activation. QuietWire's existing website release discipline still applies. The terms source carries an explicit review comment because business/legal review should occur before production activation.

The product copy deliberately avoids claims that V1 has not proven:

- no claim of cryptographic operator blindness;
- no claim that public self-service export is already available;
- no claim that every provider is already supported;
- no claim that an AI model is the authoritative owner of memory.
