# Glosario español v1.0.0

Este glosario acompaña un borrador de traducción automática en español internacional
neutral. No representa todavía una decisión lingüística definitiva para España,
Colombia ni otra comunidad hispanohablante. La revisión humana debe conservar las
diferencias regionales cuando sean materiales y evitar fingir una universalidad que
no existe.

`HTTPS`, `SHA-256`, `JSON`, `CAP`, `QWOS` y unidades técnicas permanecen sin traducir
cuando corresponda.
